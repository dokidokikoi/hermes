<div align="center">
Izumi is a powerful, feature rich, cross-platform game metadata manager scrap server. It aims to solve the metadata scraping and management of your huge game library. 
</div>

## What Izumu Provides
- Five built-in scrapers
    - bangumi
    - dlsite
    - getchu
    - 2dfan
    - ggbases
- Provides rich metadata, including tags, categories, brands, images, etc.
- Supports downloading scraped metadata to the game library directory, and also supports importing
- Search Function
